Quark Code is a native Android client for the opencode AI coding agent.

On-device mode runs the official opencode server inside a Debian guest (proot, no root needed) on loopback behind a password. Remote mode talks to the same API over LAN or Tailscale.

The agent is sandboxed: it sees only its /workspace plus the guest system. Files enter only when you import them through the built-in file manager, and leave only when you share them out.

Features: streaming chat with tool cards and permission prompts, 225+ providers with your own API keys, usage stats with cost, review diffs, workspace file browser with ZIP/text/image view, light/dark/AMOLED themes.

First download needs Wi-Fi (~200 MB, ~2.1 GB on disk). Model calls always need internet. No accounts, no tracking, no proprietary dependencies. GPL-3.0.
